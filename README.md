# DistriTech Marketplace

Marketplace B2B PHP 8 / MySQL pour les licences, équipements et services IT de DISTRITECH Maroc.

## Fonctions disponibles

- accueil et catalogue dynamique
- recherche et filtres par catégorie
- fiche produit avec version, utilisateurs et licence
- panier en session PHP
- demande de devis enregistrée dans MySQL
- catalogue de démonstration disponible même sans base de données

## Installation XAMPP

1. Copier le projet dans `C:\xampp\htdocs\DistriTech-Marketplace`.
2. Importer `database/schema.sql` dans phpMyAdmin.
3. Vérifier les identifiants dans `config/database.php`.
4. Ouvrir `http://localhost/DistriTech-Marketplace/public/`.

PHP 8.0+ et l'extension PDO MySQL sont requis.
