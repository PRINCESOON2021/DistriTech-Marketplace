# Campagne Microsoft DistriTech — V1

Objectif : générer et qualifier des prospects Microsoft 365 B2B au Maroc sans afficher de prix publics.

## Parcours
Annonce Meta / campagne Google / lien direct → landing page → formulaire multi-étapes → recommandation interne → prise de contact DistriTech.

## Produits internes
- Microsoft 365 Business Basic
- Microsoft 365 Business Standard (offre principale)
- Microsoft 365 Business Premium
- Microsoft Copilot (option ; tarification à confirmer avec Disway/Ingram)

Les coûts d'achat et règles de marge restent strictement internes et ne doivent jamais être injectés dans le HTML public.

## Formulaire public
1. Type d'activité
2. Nombre d'utilisateurs : 1–5 / 6–10 / 11–25 / 26–50 / 51–100 / 101–300 / +300
3. Utilisez-vous déjà Microsoft 365 ?
4. Messagerie actuelle : Microsoft 365 / Google Workspace / hébergeur / Exchange local / adresses personnelles / autre
5. Besoins (multi-choix) : messagerie, Office, Teams, OneDrive, collaboration, sécurité, gestion appareils, Copilot/IA, migration, sauvegarde, conseil
6. Intérêt Copilot
7. Besoin de migration
8. Délai : immédiat / <30 jours / 1–3 mois / 3–6 mois / étude
9. Coordonnées : nom, entreprise, ville, téléphone, email professionnel

## Qualification interne
La qualification n'est jamais affichée au prospect.
- Basic : besoins mail/cloud simples
- Standard : Office desktop + mail/collaboration
- Premium : sécurité et/ou gestion des appareils
- Copilot : intérêt IA explicite
- Migration : prestation de migration détectée

Priorité commerciale renforcée pour 20+ utilisateurs, migration, sécurité/Premium et démarrage sous 30 jours.
